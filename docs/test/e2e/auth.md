# ユーザ登録・認証関連

| No. | 大項目   | 中項目 | 小項目      | 操作手順                                                                                       | 期待結果                     |
|-----|-------|-----|----------|--------------------------------------------------------------------------------------------|--------------------------|
| 1   | ユーザ登録 | 正常系 |          | ①ログイン画面にアクセスして「新規登録はこちら」をクリック<br>②新規登録画面で各項目を入力して「アカウント作成」をクリック<br>③登録完了画面で「ログインはこちら」をクリック | 正しく画面遷移し、最後にログイン画面が表示される |
| 2   |       | 異常系 | 必須項目未入力  | ①ログイン画面にアクセスして「新規登録はこちら」をクリック<br>②新規登録画面で何も入力せず「アカウント作成」をクリック                              | 新規登録画面にエラーメッセージが表示される    |
| 3   |       |     | パスワード不一致 | ①ログイン画面にアクセスして「新規登録はこちら」をクリック<br>②新規登録画面でパスワードと確認用パスワードの入力値が異なる状態で各項目を入力して「アカウント作成」をクリック   | 新規登録画面にエラーメッセージが表示される    |
| 4   | ログイン  | 正常系 | 一般ユーザ    | 一般ユーザのログイン情報を入力して「ログイン」をクリック                                                               | ユーザ用ホーム画面が表示される          |
| 5   |       |     | 管理者      | 管理者のログイン情報を入力して「ログイン」をクリック                                                                 | 管理者用ホーム画面が表示される          |
| 6   |       | 異常系 |          | 不正なログイン情報を入力して「ログイン」をクリック                                                                  | ログイン画面にエラーメッセージが表示される    |
